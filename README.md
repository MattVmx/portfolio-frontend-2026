# Matías Speroni — Frontend Portfolio

Portfolio bilingüe con modo claro/oscuro, proyectos filtrables y casos interactivos.

## Stack

- Next.js 15
- React 19
- TypeScript
- CSS

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

El proyecto está preparado para desplegarse en Vercel. El tema y el idioma elegidos se guardan localmente en el navegador.
